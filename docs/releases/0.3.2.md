# 0.3.2 · Desktop 设置接口兼容修复

插件正式版，面向 **DSH 0.1.7-rc.2**；Node.js **^22.19.0 或 >=24.0.0**。不声明兼容未经测试的其他宿主版本。

- 设置读取、保存、测速和 SearXNG 引擎探测支持官方 `Origin: dsh-app://app`，仅限本机回环 HTTP Host。
- 允许该精确 Desktop 来源携带 cross-site Fetch Metadata；普通浏览器跨站请求、伪造相似来源和非回环目标仍不放行。
- 403 返回结构化 JSON；前端遇到纯文本 403、HTML 网关错误或无效 JSON 时显示明确的 HTTP 错误。
- 不改变搜索后端配置、凭据、工具权限或数据库结构。可以回退至 0.3.1。

验证：54 项自动化测试、类型检查、构建和包检查通过，包括实际本地 HTTP 路由测试。尚未实测真实 Windows/macOS Desktop 客户端。

安装：`npm install @lemoncat7/dsh-web-search@0.3.2`。
