# 网页搜索 0.3.4

## 宿主兼容

本版本明确支持 **DeepSeek Harness 0.2.1-rc.2**。包的 `engines.dsh` 与相关运行时 peerDependencies 已更新为 `^0.2.1-rc.2`，构建依赖固定为本次验证版本。其他宿主版本未由本次验证覆盖。

仍在 DSH 0.2.0-rc.2 的用户请继续使用 **0.3.3**，不要在旧宿主上强制安装本版。

## 更新

- 更新 DSH 依赖及安装兼容声明，明确支持 0.2.1-rc.2。
- 移除新版已退役的 invariants 依赖、导出和对应打包检查。
- 保留搜索、网页抓取、测速、设置及 dsh-app://app 来源兼容。

## 验证与升级

已验证隔离与正式宿主设置页面；dsh-app://app 来源检查通过，不可信来源仍被拒绝。此项不等同于完整 macOS/Windows 桌面实机验收。

安装：`dsh plugin --profile web add @lemoncat7/dsh-web-search@0.3.4`。

请先备份配置与插件数据，升级到上述宿主后再安装本版，并重启实际使用的 Profile（桌面端按其 Profile 操作）。本次不修改 DSH 核心源码，不清理或迁移生产会话数据。

详见 [DSH 0.2.1-rc.2 兼容说明](../dsh-021-compatibility.md)。
